Project 01

Counterfactual XAI 기반 자율비행 시스템 검증

자율비행 객체탐지 모델이 실패하는 환경 조건을 더 빠르게 찾기 위한 AI 검증 프로젝트.

2026.03–06Team 4XAI AnalysisCounterfactual Search

Background

자율비행 시스템의 객체탐지 모델은 기준 환경에서 높은 성능을 보이더라도 조도, 날씨, 배경 등 환경 조건이 변하면 성능이 예상하지 못한 방식으로 저하될 수 있습니다. 가능한 모든 환경 조건을 무작위로 확인하는 방식은 많은 실험을 필요로 합니다.

Objective

모델이 실패하는 환경 조건을 기존 탐색보다 빠르게 발견하는 검증 방법을 설계합니다.

객체탐지 모델의 baseline 대비 mAP50이 15%p 이상 감소하는 조건을 실패 조건으로 정의했습니다.

Structure

01Environment Variation
02Object Detection
03Performance Evaluation
04XAI Analysis
05Counterfactual Search
06Failure Detection

How It Works

환경 조건을 변화시키며 객체탐지 성능을 평가하고, 성능이 저하된 조건에서 XAI로 영향을 준 환경 요인을 분석합니다. 이 결과를 Counterfactual Search의 다음 탐색 방향에 활용해 최초 실패 조건을 찾습니다.

What I Learned

Explain → Identify → Search → Verify

AI 시스템에서는 평균 성능뿐 아니라 어떤 조건에서 실패하는지를 찾고 설명하는 과정이 중요하다는 점을 배웠습니다. XAI 결과를 실제 검증 의사결정과 연결하며 모델 분석과 시스템 검증을 하나의 흐름으로 바라보는 경험을 했습니다.
