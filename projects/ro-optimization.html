프로젝트 03

RO 비플럭스 분석 및 CIP 일정 최적화

막 성능 저하와 세척 비용 사이의 상충관계를 고려해 CIP 시점을 최적화한 퍼듀대학교 프로젝트.

2026.06–07퍼듀대학교최적화타부 탐색

배경

RO 공정에서는 막 오염으로 비플럭스가 감소하면 CIP 세척을 수행합니다. 세척을 자주 하면 막 성능을 빠르게 회복할 수 있지만 약품비와 가동 중단 비용이 증가하고, 세척을 늦추면 생산 성능 저하에 따른 손실이 커집니다.

실제 데이터에서는 세척 기준이 모든 운전 사이클에 동일하게 적용되지 않았습니다. 따라서 CIP 시점을 단순한 임계값으로 판단하기보다, 공정 데이터로 막 상태를 이해하고 성능 저하 비용과 세척 비용을 함께 고려하는 운영 의사결정 문제로 다룰 필요가 있었습니다.

목적

비플럭스와 주요 운전변수의 변화를 분석하고, 막 성능 저하 비용과 세척 비용을 함께 고려한 CIP 일정을 도출합니다.

구조

원시 공정 데이터를 분석 가능한 형태로 정리하고 모델 비교를 통해 막 상태를 해석한 뒤, 비용 목적함수와 CIP 일정 탐색으로 연결했습니다.

작동 방식

01

운전 데이터 구성 — K-water의 18개월 공정 데이터에서 6,547시간의 운전 구간과 10회의 CIP 주기를 구분했습니다.

02

이상치·결측치 처리 — 24시간 Rolling Z-score로 비플럭스·운영차압·유입압력의 비정상 스파이크를 처리하고 센서 미기록값을 변수 특성에 맞게 보간했습니다.

03

운전 상태 구분 — 운전변수는 실제 운전 사이클 내부에서만 보간하고 세척 구간은 별도로 유지한 뒤, 모델 입력에 is_operating 변수를 추가했습니다.

04

비플럭스 분석 — Ridge와 LSTM을 비교하고 비플럭스·유입압력 등 운전변수의 중요도를 확인했습니다. 제한된 데이터와 자기회귀 특성에서는 Ridge가 더 안정적인 결과를 보였습니다.

05

일정 최적화 — 막 성능 저하 손실과 CIP 비용을 목적함수로 구성하고, 그리디 탐색과 타부 탐색을 비교하며 λ에 따른 비용 균형을 확인했습니다.

담당한 부분

팀의 전체 분석·최적화 과정에서 문제 정의와 데이터 분석을 맡고, 모델 결과를 운영 의사결정의 관점으로 정리했습니다.

01 · 문제 정의

운영 문제 정식화 — 비플럭스 감소와 CIP 비용 사이의 상충관계를 운영 최적화 문제로 정리했습니다.

02 · 데이터 분석

공정변수 검토 — 주요 공정변수를 검토하고 운전 구간과 세척 구간을 구분하는 분석 과정에 참여했습니다.

03 · 결과 해석

모델 비교 — Ridge와 LSTM 결과를 데이터 규모와 자기회귀 특성 관점에서 비교하고 CIP 의사결정 문제와 연결했습니다.

04 · 결과물

자료 검토와 제출 — 영문 발표자료와 질의응답 내용을 검토하고 최종 프로젝트 자료를 제출했습니다.

배운 점

분석 → 정식화 → 최적화 → 의사결정

예측 정확도가 높은 모델을 만드는 것만으로는 실제 운영 문제를 해결할 수 없다는 점을 배웠습니다. 데이터 전처리와 모델 비교 결과를 비용 구조와 제약조건으로 연결하면서, 분석 결과를 실제 의사결정 문제로 변환하는 과정을 경험했습니다.
