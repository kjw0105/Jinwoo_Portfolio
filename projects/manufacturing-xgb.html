Project 02

공작기계 진동 데이터 기반 이상 상태 분류

진동 데이터를 활용해 이상 상태를 탐지하고 NG를 놓치지 않는 것을 우선한 머신러닝 프로젝트.

2026XGBoostFeature EngineeringThreshold Analysis

Problem

공작기계에서는 설비 상태를 나타내는 대규모 진동 데이터가 지속적으로 발생합니다. 정상 데이터에 비해 이상 데이터가 적은 환경에서는 Accuracy가 높더라도 실제 NG 상태를 놓칠 수 있습니다.

“실제 이상 상태를 얼마나 놓치지 않는가?”

My Contribution

01 · DATA

데이터 구조화

대규모 진동 데이터를 구조화했습니다.

02 · MODELING

Feature & XGBoost

Feature Engineering과 XGBoost 모델링을 수행했습니다.

03 · EVALUATION

NG 중심 평가

NG 탐지를 우선해 평가 기준과 Threshold를 분석했습니다.

Approach

Evaluation Strategy

제조 이상 탐지에서는 실제 NG를 정상으로 판단하는 False Negative가 중요한 위험이라고 보았습니다. 따라서 Accuracy 하나로 모델을 판단하지 않고 Recall, Precision, F1, F2, PR-AUC, ROC-AUC를 함께 확인했습니다.

최종 Threshold는 0.17을 적용했습니다. 전체 NG 53건 중 49건을 탐지하는 방향으로 모델을 구성했습니다.

WHAT I LEARNEDDefine the Risk → Build the Model → Evaluate What Matters

좋은 모델은 단순히 Accuracy가 높은 모델이 아니라 실제 문제에서 중요한 오류를 먼저 정의하고, 그 위험에 맞는 평가 기준을 선택한 모델이라는 점을 배웠습니다.
