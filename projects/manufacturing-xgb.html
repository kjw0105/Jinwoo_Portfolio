프로젝트 02

공작기계 진동 데이터 기반 이상 상태 분류

진동 데이터를 활용해 이상 상태를 탐지하고 NG를 놓치지 않는 것을 우선한 머신러닝 프로젝트.

2026XGBoost특징 설계임계값 분석

배경

공작기계에서는 설비 상태를 나타내는 대규모 진동 데이터가 지속적으로 발생합니다. 정상 데이터에 비해 이상 데이터가 적은 환경에서는 정확도가 높더라도 실제 NG 상태를 놓칠 수 있습니다.

이 프로젝트에서는 전체 정답률보다 실제 이상을 정상으로 판단하는 거짓 음성(False Negative)을 줄이는 것을 더 중요한 평가 관점으로 두었습니다.

목적

진동 데이터에서 실제 이상 상태를 놓치지 않는 분류 모델과 평가 기준을 설계합니다.

구조

원시 진동 데이터를 분석 가능한 형태로 정리한 뒤 특징을 구성하고, NG 탐지에 맞는 평가와 임계값 조정까지 하나의 파이프라인으로 연결했습니다.

작동 방식

01

데이터 구조화 — 244개 RAW 파일의 진동 데이터를 OK 191건과 NG 53건으로 구성하고 분석 가능한 형태로 정리했습니다.

02

모델 구성 — 25.6kHz로 수집된 진동 데이터에서 특징을 구성하고 XGBoost로 OK·NG 상태를 분류했습니다.

03

평가 기준 선택 — 재현율, 정밀도, F1, F2, PR-AUC, ROC-AUC를 함께 확인하며 NG 탐지에 맞는 임계값을 분석했습니다.
